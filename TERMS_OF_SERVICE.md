## 2. What Switch is

Switch is a browser extension that captures the login state (cookies and web
storage) of websites you explicitly grant, encrypts it on your device, and lets
you move or share that encrypted state. Sync across devices is optional.

Switch is **pre-release software**. It is supplied for evaluation and personal
use. Features may change or be withdrawn.

### Supported browsers

Switch currently targets **Chromium-based browsers** (Chrome, Edge, Brave and
similar). Firefox is **not supported**: there is no Gecko build and no
addons.mozilla.org listing. Any statement elsewhere that Firefox is supported is
a documentation error, and these terms control. There is currently **no
published store listing** for any browser; installation is from an unpacked
developer build unless the operator states otherwise.
