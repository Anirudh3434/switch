Frequently Asked Questions

Instant answers to common security, installation, and operation inquiries.

No. Absolute zero visibility. Before any cookie envelope leaves your local computer, the extension uses standard WebCrypto APIs to derive an AES-256-GCM encryption key from your Master Password using PBKDF2 (100,000 iterations with SHA-256). The cloud server only ever receives opaque ciphertext. Decryption can only take place inside your browser when your Master Password is provided.

Due to our strict zero-knowledge cryptographic guarantee, there is no master recovery backdoor. If you lose your Master Password, neither we nor any third party can decrypt your remote session envelopes. However, your local browsers continue running as usual with their current logins untouched. You can simply create a new Master Password and push fresh sessions.

Switch synchronizes standard HTTP session cookies and tokens rather than simulating automated form submissions. Because the session cookie matches an existing authenticated state, websites recognize the valid credential token. If moving between different IP subnets (e.g., home and office VPN), some services like Google Workspace may verify identity via standard push notifications.

Before Switch applies any incoming remote session into your active tab, it automatically snapshots your current cookies into a local backup record. If you applied the wrong persona or need your previous session back, click "Restore Original Cookies" from the extension popup to revert immediately.

Switch supports Google Chrome, Microsoft Edge, Brave Browser, Mozilla Firefox, Arc Browser, and Vivaldi. All Chromium-based and Gecko-based browsers are supported across Windows, macOS, and Linux.

When creating an account or verifying identity, Switch generates a cryptographically secure 6-digit one-time passcode (OTP) with an automatic 10-minute expiry. The code is dispatched directly via encrypted TLS using Gmail SMTP (smtp.gmail.com:465). Codes are hashed at rest with salt to prevent tampering, and rate-limited to eliminate brute-force vectors.

Common Diagnostics & Troubleshooting

Quick solutions for browser permissions and extension shortcuts.

Cookie Permission Prompts

Manifest V3 requires explicit permission to inspect domain cookies. If prompted, click "Allow" on the active site so Switch can read authenticated session headers.

Keyboard Shortcuts Configuration

Default shortcut is Alt + Shift + S on Windows/Linux and Option + Shift + S on macOS. You can rebind any shortcut anytime via chrome://extensions/shortcuts.

Expired or Inactive Remote Sessions

If a remote session does not authenticate, the target service's server-side session token may have expired. Simply log in again on your source browser to refresh the envelope.
