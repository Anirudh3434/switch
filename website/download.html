Load the unpacked developer build

  1. Clone or download this repository to a local folder.
  2. Open chrome://extensions in Chrome, Edge, or Brave.
  3. Enable Developer mode (top right).
  4. Choose Load unpacked and select the repository root — the folder containing manifest.json.
  5. Pin Switch, open it, and set your sync server URL. The committed default is http://localhost:8080, which only works if you run the backend locally.

Unpacked builds show browser warnings about developer mode. A signed store build is a future step; no store listing exists today.
